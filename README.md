# 📄 WebCV - Online Resume

A modern, responsive web-based CV/Resume built with HTML and CSS. Showcase your professional experience, skills, education, and portfolio in a clean and stylish format.

## ✨ Features

- **Professional Layout** – Clean and organized resume structure
- **Profile Section** – Display name, title, photo, and contact info
- **Work Experience** – Chronological job history with descriptions
- **Education** – Academic qualifications and certifications
- **Skills Section** – Visual representation of technical and soft skills
- **Portfolio/Projects** – Showcase your best work
- **Languages** – Display proficiency levels
- **Download Button** – Option to download CV as PDF
- **Responsive Design** – Looks great on desktop, tablet, and mobile
- **Print Friendly** – Optimized for printing

## 🛠️ Technologies Used

- **HTML5** – Structure and semantic layout
- **CSS3** – Styling, flexbox, grid, and animations
- **Font Awesome** – Icons for social links and sections
- **Google Fonts** – Professional typography

## 🔧 How to Run

1. Download or clone the project
2. Navigate to the project folder
3. Open `index.html` in your web browser

Or simply double-click the `index.html` file.
